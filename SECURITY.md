# Security reporting

Please report suspected vulnerabilities privately to [info@kre8ivtech.com](mailto:info@kre8ivtech.com) with the affected version, impact, and reproduction steps. Do not include credentials or customer data, and do not open a public issue with exploit details.

SiteCheck 0.1.x is an early local command-line release. Its network guard is not intended to isolate untrusted scans on a shared server. Reports may contain sensitive website content; review before sharing.

Use current dependencies, scan only authorized targets, and run the tool with the minimum network and filesystem access your use case needs.
