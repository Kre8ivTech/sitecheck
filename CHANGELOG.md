# Changelog

## 0.2.0 — 2026-10-31

- Add the web URL-entry interface, scan progress/cancellation, and report viewer/downloads.
- Add a bounded worker queue, session-owned temporary reports, expiry, and request limits.
- Add sandboxed Chromium workers, pinned public-address egress proxy, and an isolated container deployment.
- Add web/API, ownership, lifecycle, proxy, and responsive accessibility tests.

## 0.1.0 — 2026-10-31

Initial release candidate:

- Bounded same-origin crawling with robots.txt and exclusions.
- axe-core accessibility checks, internal link verification, and metadata checks.
- Configured page/visible-element journey assertions.
- Screenshots, self-contained HTML, and JSON reports.
- Baseline comparisons that preserve unverified findings.
- CLI severity thresholds, exit codes, and local demo fixtures.
